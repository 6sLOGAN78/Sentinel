## Phase Goal

**As an** operator, **I want to** see pipeline health and have failure and scale behavior proven by tests and a reproducible benchmark report, **so that** reliability and performance are demonstrated rather than claimed.

<objective>
Close the REL-01 jitter gap. Extract the event-writer's crypto full-jitter wait into a shared `internal/retry` package, then make alert-writer and detector poison retries use it. Each worker then retries transient failures with bounded, jittered backoff and keeps its existing terminal handling (error to lifecycle, no offset commit, Compose restart).

Purpose: synchronized fixed-delay retries across replicas cause thundering herds on a recovering ClickHouse/PG. Spec §11.1 requires jitter.
Output: `internal/retry`, refactored callers, and tests proving jitter bounds, attempt bounds, ctx cancellation and terminal surfacing.

**Same-module note:** run after 05-01 when not using worktrees (05-01 changes go.mod in the same wave).

Out of scope here: `alertstream/delivery.go` and `listener.go` (PG LISTEN backoff) are Phase 4 owned (04-14). Plan 05-14 converts them after Phase 4 closes.
</objective>
