## Phase Goal

**As an** operator, **I want to** see pipeline health and have failure and scale behavior proven by tests and a reproducible benchmark report, **so that** reliability and performance are demonstrated rather than claimed.

<objective>
Deliver observability as code. A Compose overlay adds pinned Prometheus, Grafana and Jaeger. Prometheus gets a scrape config for all replicas and alert rules with promtool unit tests. Grafana gets file-provisioned datasource and dashboard JSON. A static drift/hygiene test ties dashboards and rules to the real registered metric names. The pin checker is extended to every compose file.

Purpose: OBS-05 (dashboards + alert examples as code). It also gives operators the scrape/trace backends that make OBS-02/OBS-04 observable. The overlay is reused by the isolated bench stack (05-17).
Output: the observability/ tree, the overlay, checker scripts and tests.

This plan never starts a stack. It runs only `docker compose ... config` (render) and `docker run --rm` promtool against the pinned image. Disk guard: the prom image pull (~300 MB) requires ≥ 1 GB free. Otherwise the plan stops and asks the user (05-RESEARCH Pitfall 11; agent must not prune).
</objective>
