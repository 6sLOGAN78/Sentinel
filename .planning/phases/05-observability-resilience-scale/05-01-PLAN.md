## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internal network → ops listener /metrics | Prometheus scraper reads process metrics. The listener is bound to 127.0.0.1 or the compose network only |
| client → ingest PostBatch | untrusted batches drive counter increments |
| Go module proxy → build | third-party code enters the binary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-05-01-02 | Denial of service | Prometheus cardinality | mitigate | Status allowlist map, no path/route label, histogram without labels |
| T-05-01-03 | Information disclosure | /metrics exposure | mitigate | Mounted only on the ops listener (cfg.Ops bind 127.0.0.1 in Compose), never on the public Echo server. Test asserts the public router has no /metrics route |
