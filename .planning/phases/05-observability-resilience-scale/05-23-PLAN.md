<interfaces>
`func (s *QueryEventStore) SummarizeEvents(ctx, tenant string, now time.Time) (query.EventSummary, error)`. It returns RateCount (winners with occurred_at >= now-1m) and Trend (5-minute buckets from end-24h to end, where end = now truncated to SummaryBucketWidth; buckets before end only). Winner occurred_at is the argMin by the canonical tuple from `uniqueEventRowsSQL`.

Key fact for the fast path: when every row of an event_id has the same occurred_at, the winner's occurred_at equals that value no matter how ties are broken. Only identities whose rows disagree on occurred_at (conflicting payloads, allowed but unspecified by ADR 0002) need the full canonical tie-break.
</interfaces>
</context>
