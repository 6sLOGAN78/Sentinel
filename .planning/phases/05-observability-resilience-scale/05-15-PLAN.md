| T-05-15-02 | Tampering/Injection | PromQL injection | mitigate | Single package const. Query params return 400. The test asserts only qLag reaches the fake |
| T-05-15-03 | Repudiation | fake zeros while the source is down | mitigate | Per-field availability with a reason; a no-zero assertion test |
| T-05-15-04 | Denial of service | slow Prometheus stalls the API | mitigate | 2 s timeout; query-api readiness is independent of Prometheus |
| T-05-15-05 | Elevation of privilege | viewer or unknown role reads global lag | mitigate | RequireTriage (analyst/admin) server-side; viewer and unknown roles get an audited 403 (tested). Client hiding is UX only |
