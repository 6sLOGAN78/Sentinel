## Phase Goal

**As an** operator, **I want to** see pipeline health and have failure and scale behavior proven by tests and a reproducible benchmark report, **so that** reliability and performance are demonstrated rather than claimed.

<objective>
Make logs meet spec §11.3. Output is JSON by default everywhere, which decouples the `local` environment from ConsoleWriter. The field is named `timestamp`, not `time`. trace_id/span_id are attached to the request logger from the request's span context. The duplicate request_id and ip keys are removed. A credential-scrubbing test is enforced.

Purpose: OBS-03. Compose currently sets `SENTINEL_PRIMARY.ENV: local`, so container logs are not JSON today.
Output: logger/middleware changes and tests. The existing test `TestLoggerLocalUsesConsole` asserts the removed behavior, so it is rewritten in this plan.

trace_id note: this plan reads `trace.SpanContextFromContext(ctx)` (go.opentelemetry.io/otel/trace, approved in 05-01). The field is only added when the span context is valid. Plan 05-10 installs the tracer provider and otelhttp so that every request has a valid context, including unsampled ones. That plan's tests then assert trace_id on every request line. Until then, requests correctly carry no trace_id rather than a fake one.

`ip` remains in request logs exactly once. It is allowed in logs (it is not a metric label). The decision is recorded in the threat model as personal data kept for security investigation.
</objective>
