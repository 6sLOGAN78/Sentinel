## Phase Goal

**As an** operator, **I want to** see pipeline health and have failure and scale behavior proven by tests and a reproducible benchmark report, **so that** reliability and performance are demonstrated rather than claimed.

<objective>
First tracing slice, at the edge. Add configurable OpenTelemetry tracing: an injected TracerProvider with a ParentBased(TraceIDRatioBased) sampler, an OTLP/HTTP exporter and a bounded BatchSpanProcessor. The ingest HTTP server span is renamed to the route template. A `publish` span wraps the Kafka produce. A W3C `traceparent` is injected into every event record header through a small franz-go header carrier (no kotel).

Purpose: OBS-04 (ingest + publish spans, Kafka header propagation, configurable sampling). It also completes OBS-03's trace_id on ingest request logs (05-06 added the logger plumbing).
Output: tracing config, `telemetry/tracing.go`, `kafkax/headers.go`, producer injection, the chain trace-rename middleware and ingest wiring. Worker-side extraction (detect/store spans) is in 05-12. query-api server spans are in 05-14 (Phase 4 owned main.go).

**Same-module note:** this plan shares wave 3 with 05-09 (same telemetry/kafkax packages). Run it after 05-09 when not using worktrees.

No global OTel state: do not call otel.SetTracerProvider or otel.SetTextMapPropagator. The provider and propagator are passed explicitly (gochecknoglobals intent, test isolation). Tracing config uses zero-value defaults (enabled=false), so `config/config.go` (owned by pending 04-14) is not edited.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public client → ingest (traceparent header) | untrusted trace context |
| service → OTLP collector (Jaeger) | spans leave the process |
| Kafka headers | trace context crosses into workers and DLQ |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-10-01 | Denial of service | client forces 100% sampling via traceparent | mitigate | otelhttp WithPublicEndpoint (new root, link only). Tested |
| T-05-10-02 | Information disclosure | tenant/IP/principal/API key in span attributes | mitigate | Only messaging.* and batch count attributes. Route template span names. Test asserts the attribute key set |
| T-05-10-03 | Denial of service | unbounded span queue | mitigate | BatchSpanProcessor MaxQueueSize 2048 (drops), bounded batch size |
| T-05-10-04 | Spoofing | OTLP endpoint config injection | mitigate | URL validation (http/https, no userinfo). Internal network only (Compose overlay 05-13) |
| T-05-10-05 | Tampering | malformed traceparent in Kafka header | accept | The TraceContext propagator ignores invalid values, and workers start new roots |
</threat_model>
