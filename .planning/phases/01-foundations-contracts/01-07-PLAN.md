<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config (env) -> DSN/SQL | operator-supplied passwords and the database name flow into connection strings and DDL |
| migrate tool -> ClickHouse HTTP | credentials cross a network socket (localhost in dev) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | DSN construction with special-character passwords | mitigate | url.URL + url.UserPassword; round-trip test through pgxpool.ParseConfig (D-05) |
| T-07-02 | Tampering | SQL injection through the database identifier in chmigrate | mitigate | Identifier validated against `^[a-zA-Z_][a-zA-Z0-9_]*$`; migration SQL comes only from embedded files; no user data in statements |
| T-07-03 | Information Disclosure | ClickHouse password in URL / process list / logs | mitigate | Basic-auth header only; password read from env; tool never prints it; test asserts URL has no userinfo |
| T-07-04 | Denial of Service | leaked pool / hung ping at startup | mitigate | pool.Close() on ping failure; bounded 10s/5s ping timeouts; tests |
| T-07-05 | Elevation of Privilege | Redis silently unavailable at startup | mitigate | New returns error and nil client; binaries exit non-zero (D-05, ADR 0005) |
| T-07-06 | Information Disclosure | HTTP error body echoing secrets | mitigate | Error bodies read via LimitReader and only status plus file name wrapped into errors |
</threat_model>
