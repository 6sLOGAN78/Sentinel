## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client -> middleware | untrusted headers (X-Request-ID, Origin) and bodies |
| panic in handler -> response | internal state must not leak in error bodies |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | X-Request-ID echoed into logs/headers | mitigate | Length and charset validation; invalid values replaced with UUID; tested |
| T-06-02 | Information Disclosure | error responses leaking internals | mitigate | Error handler returns sanitized envelope; original error only logged; panic yields generic 500 envelope |
| T-06-03 | Denial of Service | handler panic crashing the server | mitigate | Recover registered first in `Apply`; test proves 500 envelope (D-05) |
| T-06-04 | Denial of Service | slowloris on future ingest | mitigate | `ReadHeaderTimeout` plus Read/Write/Idle timeouts in httpx |
| T-06-05 | Denial of Service | nil-pointer panic in Shutdown | mitigate | Nil-guarded Shutdown with a test (D-05) |
| T-06-06 | Spoofing | permissive CORS | accept | Origins come from config; allow-list wiring is verified when routes exist in Phase 2 |
</threat_model>
