## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host network -> published container ports | infra services must not be reachable off-host |
| .env / .env.example -> Compose | secrets are injected at runtime, never stored in the image or file |
| container registry -> local daemon | image provenance |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | published ports | mitigate | All ports bound to 127.0.0.1; `check-pins.sh images` asserts the prefix |
| T-02-02 | Information Disclosure | committed secrets in compose / .env.example | mitigate | `${VAR:?}` interpolation fails loudly without .env; .env.example placeholders `change-me-*`; `check-pins.sh env` enforces; .env gitignored |
| T-02-03 | Tampering | image tag mutation / supply chain | mitigate | Tag plus sha256 digest on all four images; `check-pins.sh` rejects `:latest` and undigested images |
| T-02-04 | Denial of Service / Tampering | destructive `make reset` | mitigate | Requires `CONFIRM=1`, local-only volumes, verified by `! make reset` |
| T-02-05 | Spoofing | placeholder targets masquerading as features | mitigate | `seed` and `bench` exit 1 with explicit "available from Phase N" message |
| T-02-06 | Tampering | password on process command line (tern, chmigrate) | mitigate | Postgres password via PGPASSWORD env, ClickHouse via env var read by the tool; never in URLs; local dev only, accepted residual |
