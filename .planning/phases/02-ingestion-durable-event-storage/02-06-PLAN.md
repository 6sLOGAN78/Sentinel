## Phase Goal

**As a** producer with a scoped API key, **I want to** submit durably acknowledged batches, **so that** my events become queryable and duplicate-safe in ClickHouse.

<objective>
Events accepted into Kafka are persisted by a bounded worker, with offsets committed only after insertion succeeds.

Purpose: Make the durable ingestion path reach real storage and recover on insert failure.
Output: Manual batch consumer, event-writer integration, failure propagation and commit-order acceptance.
</objective>
