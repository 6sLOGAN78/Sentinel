## Phase Goal

**As a** producer with a scoped API key, **I want to** submit durably acknowledged event batches, **so that** my events become queryable and duplicate-safe in ClickHouse.

<objective>
A producer can retrieve its stored events immediately and safely even when the same event ID is stored multiple times.

Purpose: Prove read-time dedupe independently of background merges before writing the Kafka consumer.
Output: Native adapter, events migration, protected lookup and no-OPTIMIZE dedupe proof.
</objective>
