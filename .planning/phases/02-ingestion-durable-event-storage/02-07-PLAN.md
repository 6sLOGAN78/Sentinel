## Phase Goal

**As a** producer with a scoped API key, **I want to** submit durably acknowledged batches, **so that** my events become queryable and duplicate-safe in ClickHouse.

<objective>
A poison event is quarantined with origin metadata while later valid events remain recoverable and correctly committed.

Purpose: Prevent malformed input from permanently blocking a partition without losing records.
Output: DLQ publishing, mixed-batch commit ordering, redaction and failure acceptance.
</objective>
